# 🛒 Product Catalog System

A **Flask-based Product Catalog Management System** that enables users to efficiently manage products through complete **CRUD (Create, Read, Update, Delete)** operations. The application demonstrates backend development fundamentals, database integration, template rendering, and responsive UI design using Flask and SQLite.

---

## 🚀 Features

* ➕ Add new products with name, price, category, and description
* 📋 Display all products in a clean and responsive catalog
* ✏️ Update existing product information
* 🗑️ Delete products with ease
* 💾 Persistent data storage using SQLite
* 🎨 Responsive user interface built with Bootstrap
* ⚡ Lightweight and easy to deploy

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/product-catalog-system.git
```

### 2. Navigate to the Project

```bash
cd product-catalog-system
```

### 3. Create a Virtual Environment (Recommended)

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

If you don't have a `requirements.txt` file yet:

```bash
pip install flask
```

### 5. Run the Application

```bash
python app.py
```

### 6. Open in Browser

```
http://127.0.0.1:5000/
```

## 💡 How It Works

1. User opens the application.
2. Existing products are fetched from the SQLite database.
3. New products can be added using a form.
4. Product details can be edited at any time.
5. Products can be deleted when no longer needed.
6. All changes are stored permanently in the database.
